# Portfólio — Thais Arruda

Site estático em HTML, CSS e JavaScript, com layout responsivo e alternância entre português e inglês.

## Como visualizar
1. Mantenha o arquivo `index.html` e a pasta `assets` no mesmo diretório.
2. Confirme que a foto está em `assets/foto-thais.png`.
3. Abra `index.html` em um navegador.

## Projetos
- **STERIBOT:** protótipo funcional com repositório público.
- **ClassificaSUS:** protótipo de apoio ao acolhimento e à classificação de risco.
- **Presença Digital:** automação para gestão de listas e registros de presença.

Os links para repositórios específicos dos projetos ClassificaSUS e Presença Digital serão atualizados quando esses códigos estiverem organizados para publicação.
